# Screenshot Guide

Add real screenshots to this folder using these suggested filenames:

- `storefront-home.png`
- `product-detail.png`
- `wishlist.png`
- `cart-checkout.png`
- `customer-account.png`
- `admin-dashboard.png`
- `admin-products.png`
- `admin-product-form.png`

## Recommended Capture Order

1. Home page hero and product sections
2. Product detail page
3. Wishlist page
4. Cart / checkout summary
5. Customer account / order tracking
6. Admin dashboard
7. Admin products page
8. Admin create/edit product form

## Tips

- Use full browser width for desktop screenshots
- Make sure the app is populated with sample products
- Prefer 1440px wide screenshots if possible
- Keep browser chrome visible only if you want a more realistic product-demo feel
